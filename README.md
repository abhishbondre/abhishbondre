### 👨‍💻 About Me

I am a developer with a deep interest in the mathematical optimization of large-scale models and scalable software architecture. Rather than relying solely on high-level abstractions, I prefer diving into the foundational mathematics of machine learning to build and understand algorithms from first principles. 

**Current Engineering Focus:**
* **`beta_solver`:** Actively developing and maintaining a PyPI-published Python package dedicated to implementing foundational machine learning algorithms from scratch.
* **`SAT-LM`:** Building a real-time satellite tracking web application that bridges orbital mechanics (TLE parsing) with privacy-first, locally-hosted LLMs.
* **Systems Architecture:** Designing robust, scalable backend architectures and managing cloud deployments.

**Leadership & Community:**
As the **Head of the Developer Club** and **IEEE Student Branch Co-Content Lead** on campus, I am passionate about driving peer learning, organizing technical workshops, and integrating modern AI tools into the student engineering community.
